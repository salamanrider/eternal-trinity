# Eternal Trinity — Isometric Squad MMORPG

An original browser-based 2D Isometric Pixel-Art MMORPG prototype inspired by classic three-character squad control RPGs.
Built to run cleanly on **Android (Termux)** and **GitHub Pages**, featuring:

- **3-Character Squad System**: Kael (Guardian), Lyra (Arcanist), Riven (Ranger)
- **Squad Formations**: Triangle, Line, Spread + Leader Switching + Obstacle Avoidance
- **Deterministic AI Combat**: Manual, Auto Attack, Full Auto, and Hold Position
- **Connected World**: Havenfall Town (Safe Zone) & Whispering Plains (Hunting Ground)
- **Multiplayer Architecture (Phase 2 Ready)**: Colyseus Server-Authoritative Room + Client Local Fallback
- **Landscape Mobile HUD**: Virtual Joystick, Tap-to-Move, Minimap, Skill Cooldowns, Quest Tracker & Inventory
